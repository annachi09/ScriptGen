Batch / Multi-NISS Processing

Runs in the background: Detect → Resolve → Generate for every NISS below, independently, using the same billing period floor and program #. One NISS failing (no anomalies, no correctly-billed reading, connection error) does not stop the rest. Each NISS keeps its own self-contained script in the combined output (no BEGIN TRANSACTION wrapper - statements run and commit on their own). Hierarchy Analysis

Finds every PRIMARY meter hierarchy (GCGT_RE_MEASUREMENT_POINT.MP_TYPE = Principal or Principal acoplado, MP status Active or Disconnected) with a reading that hasn't been billed yet, narrowed to each primary's earliest pending billing period.

ℹ️ Draft feature. The "primary" definition (MP_TYPE IN Principal / Principal acoplado, via GCGT_RE_MP_TYPE) and MP status filter (Active or Disconnected only, via GCGT_RE_MEASURE_POINT_STATUS) reflect your own correction to an earlier IND_DIST_PPAL-based draft. The pending read-status/reading-type filters were derived from live schema lookups, not yet confirmed against your own judgment — see chat for the exact query and assumptions, and flag anything that looks wrong. Results are also floored to billing periods after 10000000193 (MIN_BILLING_PERIOD) — older pending periods are left out.
